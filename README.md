# CSS-mariage-website

Feuille de style du site de mariage de Mélissa & Quentin (WeddingPlan, thème InLove).

- `mariage-v6.css` : version finale, à coller **en entier** à la place de la v5
  dans le champ CSS personnalisé du site.
- `images/` : photos de fond de chaque page. Le CSS les charge via
  `https://cdn.jsdelivr.net/gh/MKB-coder/CSS-mariage-website@main/images/…`
  (ce lien ne fonctionne que si le dépôt est **public** et la branche `main` à jour).
  Autre solution : envoyer les photos sur WeddingPlan et coller leurs adresses
  dans la partie « RÉGLAGES » en haut du CSS (`--fond-accueil`, `--fond-theme`…).
